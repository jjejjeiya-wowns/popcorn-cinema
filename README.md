# 🍿 팝콘 시네마

팝콘을 튀겨 영화를 끝까지 상영하는 가벼운 방치형(Incremental) 웹게임입니다.

**▶ 바로 하기: https://jjejjeiya-wowns.github.io/popcorn-cinema/**

## 어떤 게임인가요

- 팝콘 통을 눌러 팝콘을 튀기고, 알바생·기계 같은 시설을 사서 자동 생산을 늘립니다.
- 팝콘이 쌓이면 영화 장면이 하나씩 상영되고 그때마다 생산이 2배가 됩니다.
- 마지막 장면 ‘쿠키 영상’까지 보면 클리어!
- 뭘 살지 모르겠으면 가게 맨 위의 ‘추천’만 눌러도 끝까지 갈 수 있습니다.

| 난이도 | 영화 | 장면 | 예상 시간 |
|---|---|---|---|
| 이지 | 단편 영화 | 6 | 약 30분 |
| 노말 | TV 영화 | 9 | 약 1시간 |
| 하드 | 장편 영화 | 12 | 약 2시간 |
| 익스트림 | 감독판 | 15 | 약 3시간 |
| 카오스 | 무삭제 확장판 | 18 | 약 4시간 |

진행 상황은 브라우저에 자동 저장됩니다. 설치나 로그인은 필요 없습니다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 본문 |
| `style.css` | 디자인 |
| `core.js` | 게임 규칙(시설, 업그레이드, 난이도, 이벤트) |
| `ui.js` | 화면 동작(탭, 구매, 저장, 창) |

## 배포

GitHub Pages로 `gh-pages` 브랜치를 그대로 서비스합니다. `main`을 고친 뒤 `gh-pages`에 반영하면 1~2분 안에 사이트가 바뀝니다. 파일을 고쳤을 때는 `index.html` 안의 `?v=1` 숫자를 올려 주면 방문자 브라우저가 새 파일을 바로 받습니다.
